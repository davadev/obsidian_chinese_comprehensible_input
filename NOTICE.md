# NOTICE — Chinese Comprehensible Input

This Obsidian plugin redistributes and/or relies on third-party data:

## CC-CEDICT
- Source: https://www.mdbg.net/chinese/dictionary?page=cc-cedict
- License: CC BY-SA 4.0 (most recent MDBG distribution). The older CC-CEDICT wiki references CC BY-SA 3.0.
- How it ships: the plugin does **not** bundle CC-CEDICT. The user can opt in via Settings → Dictionary → Download CC-CEDICT, which fetches the archive from MDBG at runtime (see the pinned URLs in `src/dictionary/DictionaryDownloader.ts`) into the user's vault.
- Obligation: attribution + share-alike. Any modified/derived dictionary data shipped from this plugin must remain under CC BY-SA and credit CC-CEDICT. The seed dictionary in `src/dictionary/seedDictionary.ts` contains a few dozen hand-written single-character definitions and is not a CC-CEDICT extract.
- Test fixture: `src/tests/fixtures/cedictSample.generated.txt` is a ~200-entry subset generated by `scripts/build-cedict-fixture.mjs` (`npm run build:fixture`) and used only by the end-to-end tests. It carries the simplified → traditional → pinyin mapping and **no English glosses** — every definition is replaced with a placeholder, the same way `build-hsk-map.mjs` imports the HSK term → level mapping and nothing else. The one field kept verbatim is the `Taiwan pr. [...]` reading, because that formatted field is itself the thing under test. Nothing from this fixture reaches `main.js`; it is not part of the distributed plugin.

## HSK 2.0 level data — glxxyz/hskhsk.com
- Source: https://github.com/glxxyz/hskhsk.com  (path: `data/lists/HSK Official 2012 L{1..6}.txt`)
- License: MIT, © 2020 Alan Davies
- Usage: only the simplified-term → HSK-level (1–6) mapping is imported, generated by `scripts/build-hsk-map.mjs` into `src/dictionary/hskMap.generated.ts`. No definitions, pinyin, examples, audio, or frequency data are imported from this source.

## HSK 3.0 (2021) — headwords for the 7–9 band
- Source: https://github.com/drkameleon/complete-hsk-vocabulary (in turn from https://github.com/elkmovie/hsk30)
- License: MIT, © Yanis Zafirópulos (upstream elkmovie/hsk30 also MIT)
- Usage: only the simplified headwords of the HSK 3.0 "7–9" band and their frequency ranks are imported, to extend the topic map below. No definitions, pinyin, examples or audio are imported. The plugin's HSK *level colouring* still uses HSK 2.0 (`hskMap.generated.ts`).

## Topic map — word → subject categories
- Source: `scripts/data/topic-lists.json`, generated into `src/dictionary/topicMap.generated.ts` by `scripts/build-topic-map.mjs` (`npm run build:topics`).
- License: the topic assignments are **original work for this project**, MIT with the rest of the plugin. Every one of the 4,806 entries was assigned by hand; the remaining HSK words were reviewed and deliberately carry no topic.
- Usage: powers the dashboard's Topic coverage radar. The Chinese headwords, HSK levels and frequency ranks come from the two MIT sources above; no third-party definition or gloss text is included.
